- # 🧮 Простой калькулятор

## О проекте
Простой и понятный калькулятор на Python с базовыми математическими операциями. Проект идеально подходит для начинающих программистов, которые хотят понять основы работы с функциями, меню и обработкой пользовательского ввода. Калькулятор сохраняет историю операций для удобства.

## Функциональность
- ➕ **Сложение** - сложение двух чисел
- ➖ **Вычитание** - вычитание двух чисел  
- ✖️ **Умножение** - умножение двух чисел
- ➗ **Деление** - деление двух чисел с проверкой на ноль
- 📊 **История операций** - просмотр всех выполненных вычислений
- 🧹 **Очистка истории** - удаление истории операций

## Требования
- **Python**: версия 3.6 или выше
- **Библиотеки**: не требуются, только стандартные модули
